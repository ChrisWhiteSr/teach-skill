# Course glossary

`GLOSSARY.md`, when useful, supplies consistent terms and important distinctions for the current subject. It can introduce vocabulary before mastery; learning records separately establish what the learner understands.

## Template

```md
# {Subject} glossary

{Scope and any notation or language conventions used in this course.}

## {Optional group}

**{Term}**: {A concise definition appropriate to this context}.
- Example: {A brief example or contrasting case if useful}.
- Related terms or aliases: {Legitimate alternatives and how they differ}.
- Context: {A disciplinary, regional, historical, or technical qualification if needed}.
```

## Guidance

- Define terms at the learner's level, using familiar language or terms already explained. Avoid circular definitions.
- Preserve distinctions needed for reasoning, such as two different mechanisms with similar names. Add a diagram, pronunciation, symbol, or worked example when it helps.
- Respect established terminology and legitimate variation. Clarify which meaning applies instead of banning synonyms or asserting one field's convention universally.
- Group entries when useful for the subject. A flat list is fine for a small vocabulary.
- Revise definitions as the course becomes more precise; note substantive corrections in a learning record when they affect the learner's prior understanding.
- An AI-authored definition is a reference, not evidence that the learner can use the concept. Check understanding with an application or explanation.
