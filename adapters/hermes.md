# Runtime adapter: teach in Hermes

## Installation

Place `SKILL.md` and the format documents together in the configured skill directory. The installation convention used by these notes is `~/.hermes/skills/teach/`; confirm the actual directory in your environment.

Run the skill from the learner's course workspace. Read its checkpoint, mission, and relevant learning records before resuming.

## Capability mapping

| Teaching need | Use when available |
| --- | --- |
| Read or maintain course files | Terminal or file tools |
| Teach and give feedback | Conversation or artifacts in the chosen format |
| Create interactive HTML | File writing and a browser for verification |
| Find sources for the learner's subject | Web tools, supplied files, or suitable research tools |
| Schedule review requested by the learner | A supported scheduling tool; otherwise save a review prompt |

Use the core skill's subject selection and lesson-format guidance. An external browser may be needed for HTML; conversation and text lessons can proceed without it. Do not infer that a suggested tool, integration, or schedule is available without checking the active runtime.
