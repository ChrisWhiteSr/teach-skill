Git basics / Lesson 0001

0001 · S3: commit only the changes you choose

You will stage exactly the files you mean to commit and write a message a reader can use.

About 20 minutes. Mission link: a clean history makes your pull requests easy to review. Primary source: Pro Git, Recording Changes to the Repository.

Warm-up

You run git add app.py, then edit app.py again. What will the next commit record?

Worked example

You fixed a bug in app.py and also jotted ideas in notes.txt. Only the fix belongs in the commit:

git status
git add app.py
git commit -m "Fix the login check for empty passwords"

notes.txt stays modified and uncommitted ([1]).

Practice

  1. You changed three files but want two separate commits. Describe the commands, in order.

Mastery check

Answer from memory, without notes. A mastery check has at least five boxes like this one, each a fresh item.
